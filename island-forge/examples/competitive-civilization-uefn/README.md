# Competitive Civilization — Reload

> Thirteen tournament towns. Keep a squadmate alive.

A Reload island built from Fortnite tournament life — FNCS Headquarters at the heart, Cup towns all around. Respawn while a squadmate stands, until the late storm.

- **Mode:** Reload (Battle Royale) · **Layout:** island

## Import into a new UEFN island

1. **Create** a new UEFN project from the **Blank** island template. Name it `Competitive Civilization`.
2. **Terrain:** in Landscape mode create a landscape of about 1300 m. If your UEFN version offers *Import from File*, import `heightmap-1009.png`; otherwise sculpt using it and `minimap.png` as reference. Paint layers using `biome-paint.png`.
3. **Verse:** copy the files in `Verse/` into your project's Verse folder (Verse Explorer → your project → Add existing file, or paste into new files), then **Verse → Build Verse Code**.
4. **Layout markers:** drag `competitive_civilization_layout_device` to the island centre, choose marker props and launch a session. Build each location where its marker appears.
5. **Devices:** place and configure the devices in *Devices* below (`devices.csv` has exact coordinates).
6. **Wire the Verse devices** as described in *Verse devices*.
7. **Publish:** use `publish.txt` and upload `thumbnail.jpg`.

## Verse devices

### Layout markers — `Verse/competitive_civilization_layout.verse`
Device: `competitive_civilization_layout_device`

1. Place competitive_civilization_layout_device at the exact centre of your island (X = 0, Y = 0 if the island is centred).
2. Pick props for POIMarker, FeatureMarker and RouteMarker (a flag, sign or coloured cube works well).
3. Launch a session: markers appear at every location. Build each area, then delete the device.

### Reload respawns — `Verse/competitive_civilization_reload_respawn.verse`
Device: `competitive_civilization_reload_respawn_device`

1. In Island Settings turn Respawn on and set Spawn Location to Player Spawn Pads (or keep the bus for the first drop).
2. Place competitive_civilization_reload_respawn_device and add every Player Spawn Pad to Spawners.
3. Build a small sealed spectator box under the map, put a Teleporter in it, and set SpectatorTeleporter to it.
4. CutoffSeconds is 440s — when storm phase 4 begins.
5. Set RespawnsOffMessage to a HUD Message device ("Respawns are now OFF").

### Elimination scoring — `Verse/competitive_civilization_elimination_scoring.verse`
Device: `competitive_civilization_elimination_scoring_device`

1. Place competitive_civilization_elimination_scoring_device anywhere (a hidden device room is fine).
2. Set ScoreManager to a Score Manager device and EndGame to an End Game device.
3. ScoreToWin is 0, so the match ends on the timer or the storm.

### Match HUD — `Verse/competitive_civilization_hud.verse`
Device: `competitive_civilization_hud_device`

1. Place competitive_civilization_hud_device anywhere. Edit Title, Hint and RoundSeconds in its Details panel if you like.

> The Verse files are generated, not compiled by Island Forge. They use long-standing Fortnite Verse APIs; if a UEFN update renames something, the compiler error points at the line to fix.
