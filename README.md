## Island Forge

[`island-forge/`](island-forge/) is an AI generator for Fortnite / UEFN islands. It covers 31 island types (Battle Royale, Reload, Blitz, arenas, objective modes, party games, parkour and racing, horror, survival, tycoons), a Fortnite Creative catalog (128 prefabs, 100 galleries, 154 devices, chests, items, vehicles, creatures) and a 14-module Verse library, with Claude, Claude Code, ChatGPT, Gemini, DeepSeek, Grok, Mistral, Llama, Qwen and Kimi as AI options. It includes a React + Tailwind + WebGL web app, a TypeScript server, Python and Ruby clients, and a React Native mobile app. See [its README](island-forge/README.md).
