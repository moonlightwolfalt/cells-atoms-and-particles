# cells-atoms-and-particles
## Island Forge

[`island-forge/`](island-forge/) is an AI generator for Fortnite / UEFN islands. It covers 31 island types (Battle Royale, Reload, Blitz, arenas, objective modes, party games, parkour and racing, horror, survival, tycoons), 80 UEFN devices and a 13-module Verse library. It includes a React + Tailwind + WebGL web app, a TypeScript server, Python and Ruby clients, and a React Native mobile app. See [its README](island-forge/README.md).
